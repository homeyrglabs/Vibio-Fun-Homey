# Vibio Fun 🎮
### Bluetooth Control for Homey Pro

**Developed by RG Labs**

Bring compatible Vibio Bluetooth devices into your smart home with Vibio Fun.

Control your devices directly from Homey Pro, create automations,
and access your favorite vibration programs.

---

## ✨ Features

- Bluetooth Low Energy (BLE) connectivity
- Individual motor control on supported devices
- Six built-in vibration programs
- Homey Flow integration
- Homey Dashboard widget
- Adjustable vibration intensity
- Device connection management
- Free to use – no subscriptions

---

## 🏠 Installation

### Requirements

- Compatible Homey Pro
- Supported Vibio Bluetooth device
- Device within Bluetooth range

### Getting Started

1. Install Vibio Fun from the Homey App Store.
2. Open Homey and select **Add Device**.
3. Search for **Vibio Fun**.
4. Select your device model.
5. Follow the pairing instructions.
6. Start controlling your device.

### Install Vibio Fun

[**Install the Test Version**](https://homey.app/a/com.vibio.control/test/)

**Current status:** Awaiting Homey App Store certification.
